# Склад и касса

Учёт склада, касса, продажи, гарантия, поставщики и деньги для магазина компьютерной техники.

- `index.html` — программа
- `config.js` — почта владельца и подключение к Firebase
- `firebase-adapter.js` — вход через Google, база Firestore, скачивание файлов
- `firestore.rules` — правила доступа к базе (вставляются в консоли Firebase → Firestore → Rules)
- `opt/` — старый адрес оптового каталога, перенаправляет на https://r-bitsystem.com.kg (страница каталога — в репозитории KruzhnovSergei/diler). Данные выгружает владелец из программы («Прайс-лист» → «Оптовый каталог для дилеров»), заказы приходят в «Продажи».
- `site/` — сайт магазина Bestcomp: главная (`index.html`) и каталог (`catalog.html`). Каталог читает витрину `sitecat/*`, которую владелец выгружает из программы (вкладка расчёта ПК → «Каталог на сайте»): розничные цены = прайсы × курс × наценка категории. Поставщики и закупочные цены на сайт не попадают.

Сайт публикуется через GitHub Pages из ветки `main`. Любое изменение в репозитории появляется на сайте через 1–2 минуты.

## Сайт магазина

Сайт Bestcomp перенесён в репозиторий KruzhnovSergei/bestcomp и работает на https://bestcomp.kg. Папка `site/` здесь только перенаправляет на новый адрес — правки сайта вносить в bestcomp.
