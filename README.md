# Склад и касса

Учёт склада, касса, продажи, гарантия, поставщики и деньги для магазина компьютерной техники.

- `index.html` — программа
- `config.js` — почта владельца и подключение к Firebase
- `firebase-adapter.js` — вход через Google, база Firestore, скачивание файлов
- `firestore.rules` — правила доступа к базе (вставляются в консоли Firebase → Firestore → Rules)

Сайт публикуется через GitHub Pages из ветки `main`. Любое изменение в репозитории появляется на сайте через 1–2 минуты.
